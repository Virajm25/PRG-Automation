# Training Outline (half day)
1. **Concepts (30 min)** - drawing types, what is read vs. derived, the learning loop.
2. **Hands-on 1 (45 min)** - create a project, batch-upload the sample PDFs, watch progress, open previews from sheet numbers.
3. **Hands-on 2 (60 min)** - review the I/O list and summary; fix descriptions/tags; search and filter; add a manual row.
4. **Hands-on 3 (45 min)** - BOM totals vs. BOM lines; device summary; terminal blocks; cable schedule (derived rows, enter lengths); ferrules.
5. **Cross references (20 min)** - device, contact, coil/contact, sheet references.
6. **Export (20 min)** - Excel / PDF / CSV / XML; compare with the reference IO list and BOM Excel files.
7. **Learning and re-extract (20 min)** - make corrections, press *Re-extract*, see them applied; AI buttons (optional).
8. **Admin (20 min)** - data folder and backup (`%LOCALAPPDATA%\PRG-Extractor\prg.db`), OCR/Tesseract setup, updates.
